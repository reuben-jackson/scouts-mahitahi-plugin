# Privacy Policy - Mahi Tahi Helper

*Last updated: 2026-10-16*

Mahi Tahi Helper is a browser extension that changes how the Mahi Tahi website (`https://mahitahi.scouts.nz`) looks and behaves in your own browser.

**We do not collect, store, transmit, sell or share any data.**

- The extension runs only on `https://mahitahi.scouts.nz/*`.
- It reads information already displayed on the page (for example member names and sections) solely to sort, filter and display it, and, when you press **Download CSV**, to create a file that is saved on your own computer.
- Nothing is sent to the developer, to any server or to any third party. The extension makes no network requests of its own and has no analytics or tracking.
- It requests no browser permissions and does not use cookies, local storage or accounts.
- CSV files you download contain personal information about members. They are yours to handle in line with your group's privacy obligations.

The source code is public in this repository so you can verify these statements.

Mahi Tahi Helper is an independent community project and is not affiliated with or endorsed by Scouts NZ.

Questions: open an issue in this repository.
